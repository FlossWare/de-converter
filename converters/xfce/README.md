# XFCE Converters

XFCE desktop environment converters - Coming soon!

## Planned Converters

- `xfce-extract.py` - Extract XFCE configuration (xfconf) to JSON
- `xfce-to-fvwm.py` - Convert to fvwm configuration
- `xfce-to-jwm.py` - Convert to jwm configuration
- `xfce-to-i3.py` - Convert to i3 window manager configuration

## XFCE Configuration Locations

- `~/.config/xfce4/` - Main configuration directory
- `~/.config/xfce4/xfconf/xfce-perchannel-xml/` - Settings database
- `~/.config/xfce4/panel/` - Panel configuration
- `~/.config/xfce4/xfwm4/` - Window manager settings
