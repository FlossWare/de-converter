# KDE Plasma Converters

KDE Plasma desktop environment converters - Coming soon!

## Planned Converters

- `kde-extract.py` - Extract KDE configuration to JSON
- `kde-to-fvwm.py` - Convert to fvwm configuration
- `kde-to-jwm.py` - Convert to jwm configuration
- `kde-to-awesome.py` - Convert to awesome window manager configuration

## KDE Configuration Locations

- `~/.config/` - KDE configuration files (kwinrc, kglobalshortcutsrc, etc.)
- `~/.local/share/` - Application data and settings
- `~/.config/plasma-org.kde.plasma.desktop-appletsrc` - Panel/widget configuration

## Contributing
